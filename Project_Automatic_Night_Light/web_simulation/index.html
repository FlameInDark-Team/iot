C++ / Wiring • Arduino UNO R3 
/* Project Work: Automatic Night Light System (Ambient Light-Adaptive Luminaire)
 * Connections: LDR -> A0 (10k Pull-Down) | 5mm LED -> Pin D9 (220 Ohm Resistor) | Baud: 9600 bps */
const int LDR_PIN = A0;              // Analog input pin for LDR potential divider tap
const int LED_PIN = 9;               // Digital output pin for LED actuator
const int THRESHOLD_DARK  = 400;     // Lower hysteresis boundary (Nightfall -> Turn ON)
const int THRESHOLD_LIGHT = 500;     // Upper hysteresis boundary (Daybreak -> Turn OFF)
const int SAMPLES = 10;              // Rolling average window size
int buffer[SAMPLES]; int bufIdx = 0; long runningSum = 0;
bool ledState = false; unsigned long lastLog = 0;

void setup() {
  pinMode(LED_PIN, OUTPUT); digitalWrite(LED_PIN, LOW); // Initialize luminaire extinguished
  Serial.begin(9600);
  for (int i = 0; i < SAMPLES; i++) {
    buffer[i] = analogRead(LDR_PIN); runningSum += buffer[i]; delay(5);
  }
}

void loop() {
  runningSum -= buffer[bufIdx];
  buffer[bufIdx] = analogRead(LDR_PIN);
  runningSum += buffer[bufIdx];
  bufIdx = (bufIdx + 1) % SAMPLES;

  int filteredADC = runningSum / SAMPLES;
  float nodeV = (filteredADC * 5.0) / 1023.0;

  // Dual-Threshold Schmitt Trigger Hysteresis Comparator
  if (filteredADC <= THRESHOLD_DARK) {
    ledState = true;  digitalWrite(LED_PIN, HIGH);     // Darkness detected: Luminaire ON
  } else if (filteredADC >= THRESHOLD_LIGHT) {
    ledState = false; digitalWrite(LED_PIN, LOW);      // Daylight restored: Luminaire OFF
  }

  // Periodic Telemetry Reporting over UART Serial (Every 500 ms)
  if (millis() - lastLog >= 500) {
    lastLog = millis();
    Serial.print("ADC: "); Serial.print(filteredADC);
    Serial.print(" | V: "); Serial.print(nodeV, 2);
    Serial.print("V | Luminaire: ");
    Serial.println(ledState ? "ACTIVE (ON)" : "INACTIVE (OFF)");
  }
  delay(20);
}

Photoconductive Physics in CdS

Cadmium Sulfide (CdS) is an intrinsic II-VI direct bandgap semiconductor with an energy bandgap of Eg = 2.42 eV. Optical photo-excitation occurs when incident photon energy meets or exceeds this quantum threshold:

λcutoff = hc / Eg ≈ 512 nm (Green-Blue Spectrum)

Incoming photons break covalent bonds, elevating excess carrier density Δn = η · G · τ. Because electron mobility in CdS (μe ≈ 250 cm²/(V·s)) significantly outpaces hole mobility, electrical conductivity σ = q(nμe + pμh) spikes by over 3 orders of magnitude, collapsing resistance from >1 MΩ in darkness to <400 Ω in bright sunlight.

⚡

Potential Divider Sensitivity Optimization

Because microcontrollers cannot read bare resistance directly, the LDR is paired with a fixed pull-down resistor Rfixed to form a potential divider tapped into analog pin A0:

Vout = Vcc × [ Rfixed / (RLDR + Rfixed) ]

Differentiating sensitivity S = |dVout / dRLDR| = Vcc · Rfixed / (RLDR + Rfixed)² reveals that maximum voltage swing per lux occurs when Rfixed ≈ RLDR. For typical domestic twilight transitions (20 – 100 lux), photocell resistance hovers between 8 kΩ and 15 kΩ, proving that 10 kΩ is mathematically optimal.

📊

10-Bit SAR ADC Quantization & Filtering

The ATmega328P microcontroller incorporates a Successive Approximation Register (SAR) ADC clocked at 125 kHz, taking 13 clock cycles (104 μs) to resolve a continuous analog voltage into a 10-bit digital count:

1 LSB = Vref / 1024 = 5.0 V / 1024 = 4.8828 mV per Count

Digital output D = round((Vnode / 5.0 V) × 1023). A 10-sample rolling average boxcar filter running in SRAM eliminates high-frequency sensor noise, mains 50 Hz fluorescent flicker, and thermal drift without introducing phase delay.

🔀

Dual-Threshold Schmitt Trigger Hysteresis

Single-threshold comparators oscillate rapidly and buzz relays when ambient twilight lingers near the trip point. This design implements software Schmitt-trigger hysteresis with distinct upper and lower trip points:

Deadband Δ = TLIGHT - TDARK = 500 - 400 = 100 Counts (0.488 V)

When descending into darkness, the luminaire turns ON only when light drops to ≤ 35 lux (ADC ≤ 400). When morning dawns, the luminaire extinguishes only when light climbs past ≥ 85 lux (ADC ≥ 500), guaranteeing 100% chatter-free stability.

🔌

AC Mains Relay & Galvanic Optoisolation

To safely control a domestic 230 V AC / 50 Hz luminaire or street lighting grid, the low-voltage 5V microcontroller output must be galvanically isolated from lethal mains potentials:

Optoisolator: MOC3021 / PC817 (5,000 V RMS Galvanic Isolation)

A 2N2222 NPN BJT driver sinks the 70 mA relay coil current, while a reverse-biased 1N4007 flyback diode clamps back-EMF inductive kickback voltages (V = -L · di/dt) that would otherwise destroy the ATmega328P I/O port.

🌐

IoT Cloud & Municipal Smart Grid Integration

The edge controller architecture readily integrates into smart city street lighting grids by pairing or upgrading the ATmega328P with an ESP32 or ESP8266 Wi-Fi / LoRaWAN transceiver:

Protocol: MQTT over TLS (Port 8883) | Payload: JSON Telemetry Stream

Node publishes lux values, node voltage, burn-time hours, and relay status to cloud dashboards (AWS IoT Core, ThingSpeak), enabling predictive maintenance, dynamic dimming, and autonomous fault detection across thousands of municipal luminaire nodes.

1. Aim of the Experiment / Project

To design, assemble, calibrate, and program an Automatic Night Light System using an Arduino UNO R3 (ATmega328P), a Cadmium Sulfide (CdS) Light Dependent Resistor (LDR), and a fixed potential divider network. The system autonomously senses ambient illuminance levels, executes a 10-sample rolling-average noise filter, and implements a software dual-threshold Schmitt-trigger hysteresis comparator to switch an LED luminaire or AC mains relay ON during darkness and OFF at daybreak without relay contact chattering.

4. Working Principle & Mathematical Foundations

A. Photoconductive Transduction: Cadmium Sulfide (CdS) is a direct bandgap semiconductor with Eg = 2.42 eV. Optical photo-excitation occurs when incident photon energy meets or exceeds this threshold:

λcutoff = hc / Eg = (6.626 × 10⁻³⁴ J·s × 3 × 10⁸ m/s) / (2.42 × 1.602 × 10⁻¹⁹ J) ≈ 512 nm

In darkness, carrier density is near zero, yielding RLDR > 1 MΩ. In bright daylight, incoming photons create electron-hole pairs, elevating conductivity σ = q(nμe + pμh) and dropping RLDR below 400 Ω.

B. Potential Divider Equation: The analog voltage Vnode tapped into pin A0 is governed by Ohm's potential division:

Vout = Vcc × [ Rfixed / (RLDR + Rfixed) ]

Maximum sensitivity S = |dVout / dRLDR| occurs when Rfixed ≈ RLDR. For typical dusk transitions (20–100 lux), RLDR ≈ 8–15 kΩ, proving that 10 kΩ is mathematically optimal.

C. 10-Bit SAR ADC Quantization: The ATmega328P Successive Approximation Register (SAR) ADC converts the continuous node voltage into a discrete 10-bit integer:

ADC Value (D) = round( [ Vnode / 5.0 V ] × 1023 )  |  1 LSB = 5.0 V / 1024 = 4.8828 mV per count

D. Dual-Threshold Schmitt Trigger Hysteresis: Single-threshold comparators oscillate rapidly when light hovers near the trip point. Software hysteresis introduces dual asymmetric thresholds with a deadband:

Deadband Δ = TLIGHT - TDARK = 500 - 400 = 100 Counts (0.488 V)
• Nightfall: If Filtered ADC ≤ 400 counts (≤ 1.95 V / ≈ 35 lux) → Turn Luminaire ON
• Daybreak: If Filtered ADC ≥ 500 counts (≥ 2.44 V / ≈ 85 lux) → Turn Luminaire OFF
• Deadband: If 400 < ADC < 500 → Retain Previous Luminaire State (Chatter-Free)

5. Step-by-Step Practical Laboratory Procedure

  1. Component Verification: Inspect the Arduino UNO R3, LDR (GL5528), 10 kΩ resistor (Brown-Black-Orange), 220 Ω resistor (Red-Red-Brown), and red 5mm LED for physical integrity.
  2. Breadboard Power Distribution: Connect a red jumper wire from the Arduino 5V pin to the breadboard positive rail (+) and a black jumper wire from Arduino GND to the negative rail (-).
  3. LDR Voltage Divider Assembly: Insert the LDR into two separate terminal rows. Connect one lead to the +5V bus and the other lead to an intermediate tie point row. Insert one lead of the 10 kΩ pull-down resistor into the same intermediate row, and connect its other lead to the GND rail.
  4. Analog Signal Tap: Insert a green jumper wire from the LDR-resistor junction row into Arduino analog input pin A0.
  5. Actuator LED Circuit: Insert the 5mm LED into two separate rows. Connect the cathode (shorter flat lead) to the GND rail. Connect the anode (longer lead) in series with the 220 Ω current-limiting resistor to Arduino digital pin D9.
  6. Firmware Compilation & Flashing: Connect the Arduino to the laboratory computer using the USB A-to-B cable. Open the Arduino IDE, select board "Arduino Uno" and the corresponding COM port. Paste the production sketch, verify/compile (Ctrl+R), and upload (Ctrl+U).
  7. Calibration & Serial Monitoring: Open the Serial Monitor at 9600 baud. Observe telemetry under direct room illumination (ADC ≈ 800–850, LED OFF). Progressively shade the sensor with your hand; observe ADC dropping below 400 and the LED turning ON. Uncover the sensor and confirm the LED extinguishes smoothly once ADC exceeds 500.

 * Connections: LDR -> A0 (10k Pull-Down) | LED -> Pin D9 (220 Ohm) | Baud: 9600

8. Results & Practical Inferences

  • Automatic Operation Verified: The ambient light-adaptive night light circuit successfully switches the LED luminaire ON when illuminance falls below 35 lux (ADC ≤ 400 counts / 1.95 V) and extinguishes it when daylight rises above 85 lux (ADC ≥ 500 counts / 2.44 V).
  • Zero Chatter Stability: The 100-count software Schmitt-trigger hysteresis deadband (0.488 V) completely eliminated contact buzzing, relay chatter, and optical oscillation during slow twilight transitions.
  • Noise Immunity: The 10-sample rolling average boxcar filter effectively suppressed 50 Hz fluorescent flicker and transient shadow noise without causing perceptible phase delay.

9. Precautions & Practical Checklist

  • LED Polarity: Always connect the longer lead (Anode) to pin D9 via the 220 Ω resistor and the shorter lead (Cathode) to GND. Reverse polarity will prevent illumination.
  • Optical Feedback Glare: Ensure the actuator LED does not cast direct optical glare onto the LDR photocell. Optical feedback will cause self-induced oscillatory blinking.
  • Common Ground Reference: Verify that both the 10 kΩ potential divider resistor and the LED cathode share a common GND rail with the Arduino UNO.
  • Current Limiting: Never connect an LED directly to an Arduino digital pin without a series current-limiting resistor (minimum 220 Ω) to prevent burning out the ATmega328P output driver transistors.
  • Baud Rate Matching: Ensure the Arduino IDE Serial Monitor baud rate is explicitly set to 9600 baud; mismatched baud rates will output corrupted telemetry characters.
